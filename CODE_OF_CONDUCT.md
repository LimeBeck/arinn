# Code of Conduct

Arinn adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be respectful and constructive, assume good intent, and focus on the work. Harassment, personal attacks, discriminatory language and publishing others' private information are not acceptable in any project space — issues, pull requests, discussions and any other channel.

## Enforcement

Report unacceptable behaviour privately to the project maintainer, [@LimeBeck](https://github.com/LimeBeck), for example through a [private security advisory](https://github.com/LimeBeck/arinn/security/advisories/new) if no other private channel is available. All reports are reviewed confidentially. The maintainer applies the enforcement guidelines of the Contributor Covenant: correction, warning, temporary ban or permanent ban, depending on the impact.
