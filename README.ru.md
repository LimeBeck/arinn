## Что такое Arinn

Arinn (древнескандинавское «очаг») объединяет привычные Linux-приложения в одном интерфейсе для телевизора. Откройте Home поверх приложения, затем вернитесь к нему кнопкой «Назад», не закрывая его.

В текущих исходниках доступны:

- **Home и «Продолжить».** Возврат к работающим приложениям и медиа с сохранённым прогрессом; фон текущего приложения и видимый фокус управления пультом.
- **Сайты и открытые сервисы.** Экран «Сайт или поиск», сохранение веб-ярлыков и переключение между управляемыми окнами Chrome/Chromium. Браузер подключается через расширение из пакета.
- **Приложения и игры.** Запуск установленных приложений, Steam и ES-DE. Игры выбираются внутри их лаунчера; собственного каталога игр Steam или эмуляторов в Arinn нет.
- **Медиатека и воспроизведение.** Сканирование локальных и уже смонтированных папок, фильмы и сериалы, воспроизведение через mpv. Панель плеера предлагает перемотку, выбор звука/субтитров и управление воспроизведением, когда провайдер поддерживает эти действия.
- **Загрузки.** Подключённая очередь Transmission, управление заданиями и переход к импортированному медиа в библиотеке. Сам Transmission нужно установить и настроить отдельно.
- **Настройки.** Параметры провайдеров и списки папок медиатеки. Текст и пути вводятся экранной клавиатурой; графический выбор папки пока не реализован.
- **Управление поверх приложения.** Глобальный Home, быстрое меню и экранная клавиатура вызываются настраиваемыми сочетаниями. Действия питания зависят от рабочего окружения, сессии и доступных возможностей.

У Arinn общее домашнее пространство без собственных аккаунтов и профилей. Оболочкой управляют пульт со стандартными клавишами, клавиатура или аэромышь; управление внутри внешнего приложения зависит от самого приложения.

Интеграции работают отдельными процессами плагинов. Настройка описана в [руководстве пользователя](https://limebeck.github.io/arinn/guide/) на английском.

## Превью интерфейса

Четыре кадра сняты с текущих Qt/QML-экранов через `tests/ui/visual` при 1920×1080. Сервисы и домены `.example` вымышлены, иконки нейтральны, иллюстрации — собственные заглушки, часы фиксированы. Съёмка не подключается к демону и не управляет рабочим столом; она не подтверждает прохождение тестов на реальном телевизоре.

## Статус

Репозиторий открыт, проект остаётся pre-alpha. Реализованы демон, CLI, SDK плагинов и подключённая Qt-оболочка; в исходниках есть браузерная интеграция, медиатека/mpv, Transmission, настройки и отдельные сессии входа. Наличие реализации не означает, что проверены все сервисы, телевизоры, кодеки и рабочие окружения.

[Роадмап](ROADMAP.md) определяет статусы фаз и критериев приёмки. Завершённые этапы ядра/приложений и оставшиеся проверки браузера, медиа и MVP — не перечень уже подключённых экранов. В [Releases](https://github.com/LimeBeck/arinn/releases) доступны предрелизные пакеты и снимки исходников; стабильного выпуска нет. Сверяйте коммит релиза: старый пакет может отличаться от этого README.

## Требования

- Arch Linux или EndeavourOS;
- KDE Plasma 6 на **Wayland** для основной конфигурации; для X11/XFCE см. [настройку и ограничения](docs/architecture/x11-ewmh.md);
- пользовательская сессия systemd;
- пульт, клавиатура или аэромышь со стандартными клавишами.

Для сборки: Rust (edition 2024), CMake ≥ 3.24, Ninja, компилятор C++20, Qt 6 ≥ 6.8 (Quick, Quick Controls, Quick Test, DBus, Test, SVG), Python 3, `qdbus6`, libcurl, libunwind и OpenSSL; Node.js нужен для тестов адаптеров. Sentry native и toml++ загружаются с проверкой контрольных сумм. Диагностика по умолчанию выключена; [настройка и ограничения](docs/architecture/telemetry.md).

```sh
sudo pacman -S --needed rust cmake ninja qt6-base qt6-declarative qt6-svg qt6-tools python nodejs curl libunwind openssl
```

## Попробовать прототип

Скачайте основной x86_64-пакет Arch и `SHA256SUMS` из одного [релиза](https://github.com/LimeBeck/arinn/releases). Перед установкой сравните SHA-256 пакета со строкой в файле сумм. Вместо шаблона укажите настоящее имя файла:

```sh
sha256sum ./arinn-*.pkg.tar.zst
sudo pacman -U ./arinn-<version>-<release>-x86_64.pkg.tar.zst
```

Стабильного выпуска нет; текущие исходники могут быть новее опубликованного пакета. Установка не запускает сессию и не включает автозапуск. Чтобы Arinn стартовал при входе в KDE Plasma (Wayland), один раз включите пользовательскую цель сессии и войдите снова:

```sh
systemctl --user enable arinn-session.target    # демон, оболочка и адаптер KWin при входе
systemctl --user disable arinn-session.target   # больше не запускать при входе
systemctl --user stop arinn-session.target      # остановить в текущей сессии
```

Перед удалением пакета цель нужно выключить. Сборка и запуск текущего прототипа из исходников в своей сессии Plasma:

```sh
git clone https://github.com/LimeBeck/arinn.git
cd arinn
cargo build --locked
cmake -S . -B build -G Ninja
cmake --build build

python scripts/phase0-session.py start   # запустить демон, демо-плагин, оболочку и адаптер KWin
python scripts/phase0-session.py stop    # всё остановить и выгрузить адаптер
```

Прототип работает во временных пользовательских юнитах systemd и в скрипте KWin, загруженном только на текущую сессию; ничего не устанавливается постоянно. Подробнее: [Phase 0 runbook](docs/architecture/phase-0-runbook.md) (на английском).

## Управление

| Клавиша | Действие |
| --- | --- |
| Meta+F12, Home на пульте | Глобальный Home: Arinn поверх текущего приложения (`home_shortcut` в `config.toml`) |
| Meta+F11, Menu (≡) на пульте | Быстрое меню: боковая панель поверх текущего приложения (`quick_menu_shortcut` в `config.toml`). Внутри Arinn Menu открывает навигацию |
| Meta+F10, микрофон на пульте | Экранная клавиатура поверх текущего приложения; повторное нажатие скрывает её (`keyboard_shortcut` в `config.toml`) |
| Питание (⏻) на пульте | Меню питания Arinn вместо диалога питания рабочего стола, пока Arinn запущен. На экране блокировки ничего не происходит. Более старая KDE Plasma (до 6.7) и обычный рабочий стол XFCE сохраняют свой диалог; в XFCE Arinn забирает кнопку только в отдельном сеансе «Arinn (XFCE)» |
| Стрелки | Перемещение фокуса |
| Enter | Выбор |
| Esc / Backspace | Назад: закрыть Home и вернуться в приложение; если приложения нет — открыть навигацию |

Пульты вроде аэромыши G60S Pro отправляют те же клавиши, драйвер не нужен.
