## Что такое Arinn

Arinn (древнескандинавское «очаг») превращает компьютер за телевизором в понятный TV-интерфейс: берёте пульт и выбираете, *чем заняться*, а не *какое приложение запустить*.

Arinn не заменяет браузер, плеер или игровой лаунчер. Он управляет уже установленными приложениями и работает поверх них:

- **Home поверх всего.** Нажмите Home в Chrome, Steam или игре — Arinn появится поверх; нажмите «Назад» — вернётесь туда же.
- **Одна строка «Продолжить»** для недосмотренного фильма, открытой вкладки и запущенной игры.
- **Онлайн-кинотеатры отдельными плитками** — Кинопоиск, IVI, YouTube открываются сразу, без закладок.
- **Steam и EmulationStation** — полноценные точки входа.
- **Медиатека** фильмов и сериалов из локальных и сетевых папок; воспроизведение в mpv с экранным меню Arinn, выбором аудио и субтитров и продолжением просмотра.
- **Загрузки** из Transmission: скачанные фильмы появляются в медиатеке.
- **Под пульт:** всё управляется стрелками, OK и «Назад» с трёх метров; аэромышь тоже работает.
- **Общий дом:** без аккаунтов, профилей и входа.

## Требования

- Arch Linux или EndeavourOS;
- KDE Plasma 6 на **Wayland**;
- пользовательская сессия systemd;
- пульт, клавиатура или аэромышь со стандартными клавишами.

Для сборки: Rust (edition 2024), CMake ≥ 3.24, Ninja, компилятор C++20, Qt 6 ≥ 6.6 (Quick, Quick Controls, Quick Test, DBus, Test), Python 3, `qdbus6`.

```sh
sudo pacman -S --needed rust cmake ninja qt6-base qt6-declarative python nodejs
```

## Попробовать прототип

Пакетов пока нет. Сборка и запуск прототипа Phase 0 в своей сессии Plasma:

```sh
git clone https://github.com/LimeBeck/arinn.git
cd arinn
cargo build --locked
cmake -S . -B build -G Ninja
cmake --build build

python scripts/phase0-session.py start   # запустить демон, демо-плагин, оболочку и адаптер KWin
python scripts/phase0-session.py stop    # всё остановить и выгрузить адаптер
```

Прототип работает во временных пользовательских юнитах systemd и в скрипте KWin, загруженном только на текущую сессию; ничего не устанавливается постоянно. Подробнее: [Phase 0 runbook](docs/architecture/phase-0-runbook.md) (на английском).

## Управление

| Клавиша | Действие |
| --- | --- |
| Meta+F12 | Глобальный Home: Arinn поверх текущего приложения (настраивается) |
| Стрелки | Перемещение фокуса |
| Enter | Выбор |
| Esc / Backspace | Назад: закрыть Home и вернуться в приложение; если приложения нет — открыть навигацию |

Пульты вроде аэромыши G60S Pro отправляют те же клавиши, драйвер не нужен.
