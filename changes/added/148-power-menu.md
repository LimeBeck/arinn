- Shell: global navigation › Power now opens the power menu. Sleep, Restart and Shut down go to the system through the daemon; the menu shows which actions the system allows, names the application that blocks one, lists the running applications that will close, and shows the system's refusal instead of a guess. An accepted request shows a waiting state, never success by itself ([#148](https://github.com/LimeBeck/arinn/issues/148), [ADR-0108](docs/adr/0108-system-control.md)).
- Shell: the volume and mute keys change the system volume while Arinn is on screen (Volume Up also turns muted sound back on) and show the volume HUD from the design handoff ([#148](https://github.com/LimeBeck/arinn/issues/148)).
