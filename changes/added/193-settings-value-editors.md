- Settings value editors open as sheets: an enum list with paging, an integer stepper with bounds and hold acceleration, and a string field that asks for a keyboard when none is attached. A disabled row stays visible with a lock and “Cannot be changed now”. Saving shows a pending spinner, a toast when the value is applied, a row note when it applies at the next start, and the daemon’s error text when it is rejected. Paths stay plain text ([ADR-0065](docs/adr/0065-provider-settings-contract.md)).
