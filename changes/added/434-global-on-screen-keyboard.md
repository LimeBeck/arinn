- The on-screen keyboard also types into the focused application: `keyboard_shortcut` (default Meta+F10) or the remote's microphone opens it over the application, which keeps focus. The remote's arrows, OK and Back drive the panel. Every other key still reaches the application, and the text goes only into the window that had focus. A lock, focus loss, Back or Home closes the panel; nothing typed is logged or remembered ([ADR-0105](docs/adr/0105-global-on-screen-keyboard-platform-text-delivery.md), [#434](https://github.com/LimeBeck/arinn/issues/434)).
- X11/EWMH: the adapter delivers the text with XTest, independent of the keyboard layout. KDE Plasma 6/Wayland: the new `arinn-input-method` is KWin's input method. The daemon selects it only when no other virtual keyboard is chosen, and keeps a KWin window rule so the panel never takes focus.
- The package installs a udev hwdb entry that remaps the Geniatron G60S PRO BT microphone button (`KEY_VOICECOMMAND`, which Qt and X11 cannot use) to `KEY_PROG1` (Launch1).
