- Quick menu: `quick_menu_shortcut` (default Meta+F11) in `config.toml` and the remote's Menu key (≡; Qt Menu and MenuKB, only while another window has focus, so Menu keeps toggling navigation inside Arinn) open a side sheet over the running application with Now playing and play/pause, the sound and network state, Sleep and Power, Open Home and Close Arinn. Back returns to the same application. On KDE the daemon writes the keys to the new KWin action "Arinn: Quick menu"; the X11/EWMH adapter grabs them next to the Home keys ([ADR-0106](docs/adr/0106-quick-menu-presentation.md), [#439](https://github.com/LimeBeck/arinn/issues/439)).
