- Daemon: a new `SystemControl1` interface lets the shell suspend, restart or power off the computer through logind and change the volume or mute. It respects every block inhibitor, never asks for authorization, reports refusals as typed errors and refuses calls from plugins ([ADR-0108](docs/adr/0108-system-control.md), [#464](https://github.com/LimeBeck/arinn/issues/464)). The shell's power menu and volume HUD follow.
