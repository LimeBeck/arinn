- The remote's power button (⏻) opens Arinn's power menu instead of the desktop's power dialog while Arinn runs: over an application the shell comes up as for Home with the menu open, Back leaves Home on screen, the key ends ambient and does nothing on the lock screen. On KDE Plasma, PowerDevil's power-button shortcut is set aside only for the running session, nothing in the user's settings is written, and it is given back when Arinn stops; logind's own power-button handling is inhibited while Arinn has the key. In the dedicated Arinn XFCE session, xfce4-power-manager's power-button action is "do nothing" while Arinn runs and the user's value comes back when it stops; the ordinary XFCE desktop is not changed. Arinn holds the key only while its shell is running; when the shell closes or fails, the desktop handles the button again. A system autostart entry restores the XFCE setting at the next XFCE login after an unclean end of the dedicated session ([ADR-0111](docs/adr/0111-power-key.md), [#481](https://github.com/LimeBeck/arinn/issues/481)).
