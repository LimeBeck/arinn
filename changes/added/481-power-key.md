- The remote's power button (⏻) opens Arinn's power menu instead of the desktop's power dialog while Arinn runs: over an application the shell comes up as for Home with the menu open, Back leaves Home on screen, the key ends ambient and does nothing on the lock screen. On KDE Plasma, PowerDevil's power-button shortcut is set aside only for the running session, nothing in the user's settings is written, and it is given back when Arinn stops; logind's own power-button handling is inhibited while Arinn has the key. Under XFCE with xfce4-power-manager the desktop keeps the key for now ([ADR-0111](docs/adr/0111-power-key.md), [#481](https://github.com/LimeBeck/arinn/issues/481)).
