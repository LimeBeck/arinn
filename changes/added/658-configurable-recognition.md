- The library recognises ordinal seasons such as `2nd Season` in folder and file names, so such episodes are no longer listed as films. Further season and episode markers can be added as rules in the library settings in `config.toml`, tried first with `arinn-plugin-library --check-recognition`, and applied by restarting only the library provider ([#658](https://github.com/LimeBeck/arinn/issues/658)).
