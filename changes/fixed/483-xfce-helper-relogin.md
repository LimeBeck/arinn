- "Arinn (XFCE)" session and the opt-in XFCE autostart: after a fast re-login, Arinn now starts even while the previous login is still stopping it. The XFCE launcher (`arinn-xfce-session`) waits up to 60 s for the previous login's launcher to release `org.arinn.XfceSession` instead of exiting as a duplicate. The session entry logs `arinn-session: Arinn did not start; the desktop continues without it` when its launcher gives up. A session-mode file with a NUL byte is no longer read as `desktop` ([#483](https://github.com/LimeBeck/arinn/issues/483)).
