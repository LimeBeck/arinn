- Reading the last page of a paged snapshot now releases its lease. Before, every lease lived for 30 seconds, so the daemon's periodic re-reads of a large application list, library or session list ran the provider out of leases and reads failed with `Unavailable` from time to time. The daemon also drops a vanished client's leases for sessions, library, resume and download rows, not only applications and tabs ([#616](https://github.com/LimeBeck/arinn/issues/616)).
