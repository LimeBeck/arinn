- Home no longer shows `undefined` in the hero for an open web service, and no longer adds a blank Continue card for an idle player without a title ([#757](https://github.com/LimeBeck/arinn/issues/757)).
- The hero names what the focused card is ("Film · 2024", "Series · S1 E4") instead of repeating the row label, and calls a web service by its shortcut name or by the page title without the site suffix ([#757](https://github.com/LimeBeck/arinn/issues/757)).
- A running application's tile shows its running dot, and its windows show the application's icon instead of a letter ([#757](https://github.com/LimeBeck/arinn/issues/757)).
- Favourites with an icon that did not load show no empty chip; letters sit on a neutral chip instead of a pastel square; the launch overlay shows the application's icon, with no colour glow and no extra "Working…" toast ([#757](https://github.com/LimeBeck/arinn/issues/757)).
- Over a running application the floor light takes the application's hue, and the near state darkens the application's own controls behind Home's header and lowest row ([#757](https://github.com/LimeBeck/arinn/issues/757), [ADR-0140](docs/adr/0140-tv-review-visual-decisions.md)).
