BUILT IN THE OPEN

A small project.
A thoughtful beginning.

Arinn is pre-alpha. You can try the connected interface today; everyday use on a real TV still needs testing across hardware and services. There is no stable release yet.

Follow the roadmap ↗
Available to explore

Home and Back, installed apps and game launchers, website tiles, browser switching, local media, playback controls, the download queue and settings.

Still in progress

Power and ambient features, curated Home favorites, and testing on real TVs and X11 setups. Downloads and managed-playback media keys are connected in current source builds; older packages may differ.

Free & open source

Application code under GPL-3.0-or-later. Your household shares one Home screen. Optional diagnostics are disabled by default.
